## What I built

### `README.md`
- **The problem and the solution:** why students need the tool (mixed
  downloads, duplicate files) and a before/after example of a real folder.
- **Features table:** sorting by course and type, duplicate detection,
  dry run, undo, never overwriting, safety checks, CLI and GUI.
- **Usage:** installation (Python 3.9+, no extra packages), every command and
  option in tables, real example output, exit codes, and how to open the GUI.
- **Project structure:** what every folder and script is for, as required by
  the brief.
- **How the code works:** step-by-step explanation of the main functions.
- **Robustness:** the list of bad inputs the tool handles safely.
- **Course topics used:** where functions, loops, file I/O and automation
  appear in the code.

  validation (robustness).
